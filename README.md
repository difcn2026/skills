# 认知 SKILL 全家桶 · 22 Skills Cognitive Loop

这是一个**认知 SKILL 全家桶**，共 **22 个** agent skills。它们不是一个零散工具合集，而是一条完整认知闭环：从“想之前”的准备，到“想之中”的思考，再到“想之后”的反哺，最后纵向打深“校准”这一口井。

```text
想之前（9 个）
   ↓
想之中（10 个）
   ↓
想之后（2 个）
   ↓
想更深（1 个）
   ↓
反哺下一轮“想之前”
```

所有 skills 遵循通用 Agent Skills 规范（`SKILL.md`），**与模型无关**：Claude Code、Codex、Cursor、Cline、Windsurf 等框架均可用；接入任意 OpenAI 兼容 API 均可驱动，包括 Kimi K3、DeepSeek V4、Claude、GPT 系列。中文任务同样适用。

---

## 第一批 · 想之前（9 个）

准备认知工作所需的工程、压缩、决策、生态定位与基础设施。

| Skill | 一句话 | 什么时候用 |
|-------|--------|-----------|
| `decide-whether` | 把纠结的「要不要做」压成一条可复用的决策规则 | 你说「我该不该…」「我不确定要不要…」 |
| `test-my-assumption` | 用外部证据检验你的核心假设，而不是空想 | 你有个可证伪的假设想验证 |
| `remember-task-path` | 记住任务走过的路，同类任务下次省 token | 同类任务反复出现 |
| `find-right-skill` | 边搜边问，找到你真正需要的能力，而不是第一个答案 | 你说「有没有做 X 的技能」 |
| `find-your-niche` | 在主流选项和你的真实需求之间，定位你该站的位置 | 你觉得市面上的选项「总觉得哪里不对」 |
| `build-incrementally` | 验收标准写不清时，边做边验地一步步构建 | 你要「正确」，但说不清最终长什么样 |
| `explore-with-evidence` | 方向不明时一小步一小步试，每步用证据决定下一步 | 要探索，但答案太重要不能随便扔 |
| `keep-it-precise` | 压到最小，同时保住数字、否定词等不能丢的精度 | 既要简短，又不能丢失关键细节 |
| `compress-to-budget` | 压进硬性预算（字数、一屏、尺寸），同时保持辨识度 | 有明确的篇幅限制，还要和竞品区分 |

## 第二批 · 想之中（10 个）

覆盖“想”这个动作本身：理解 → 判断 → 决策 → 元认知。

| Skill | 一句话 | 什么时候用 |
|-------|--------|-----------|
| `make-it-solvable` | 把说不清的诉求变成「边界+解」的可解单元 | 你说“帮我改进 X”，但不清楚该先想清楚还是直接做 |
| `know-what-evidence-allows` | 判断这份证据允许你说什么、做什么，别过度宣称 | 你拿一个相关性想做预测、解释、干预或归因 |
| `find-the-real-cause` | 用多个“差一点”的替代结局照出真正改变结局的那一步 | 复盘时有人说“早就注定”或“假如当初…” |
| `update-your-belief` | 量出你该更新多少 vs 实际更新多少，一步步补上缺口 | 强证据出现但你只改了一点点 |
| `pick-the-right-baseline` | 判断个例前先选对参考基准，别让生动细节扭曲基础率 | 个案“看着典型但统计罕见”，或印象与基础率打架 |
| `rank-what-to-keep` | 无法打分时排序——让被放弃者刻进保留者，最终选择让一切牺牲值得 | 多个候选必须只留一个，但打不了分 |
| `know-when-to-stop` | 把已投入分馏成“沉没”与“可转化”，停止=结束一个方向+带走资产 | 你听到“都走到这了”“停就是认输” |
| `negotiate-the-constraints` | 在约束层谈判冲突，而不是把解打折 | 你面对“既要 A 又要 B 但…”的硬限制 |
| `sense-the-loop` | 知道后果链该停在哪——因果第一次回到自己的地方 | “接下来会怎样”越推越多，你想知道该想到几层 |
| `catch-your-bias` | 像显影底片一样让偏误污染现形，给出坐标+阻断动作 | 你怀疑自己当前的推理歪了，但说不上来 |

## 第三批 · 想之后（2 个）

让结论和教训反哺思考的起点，形成自我生长的认知闭环。

| Skill | 一句话 | 什么时候用 |
|-------|--------|-----------|
| `extract-the-lesson` | 把教训从“过去的属性”改写成“未来的接口”——给每个教训绑定一个召回信号 | 复盘结论写了又忘，同一个错反复犯，却说不清“下次什么时候该想起它” |
| `name-the-concept` | 给“想明白了但说不清”的东西装上名字（接口），让它真正变成可调用的概念 | 你总说“有这么个东西…”“说不上来”，一个理解反复描述却用不起来 |

## 第四批 · 想更深（1 个）

纵向打深“校准”——判断的准确度，与对自己认知的把握度。

| Skill | 一句话 | 什么时候用 |
|-------|--------|-----------|
| `calibrate-your-forecast` | 把“我觉得我有多准”拆成三个可事后解剖的器官，结果落地时机械暴露偏差，不靠自省 | 你给出一个带置信度的预测，想知道自己到底有多准，或总在没料到的地方翻车 |

## 兼容性

- **框架**：Claude Code、Codex、Cursor、Cline、Windsurf，以及任何支持 agent skills 的运行时
- **模型后端**：在上述框架中接入任意 OpenAI 兼容 API 均可驱动，包括 **Kimi K3**、**DeepSeek V4**、Claude、GPT 系列
- **语言**：中文任务同样适用；description 面向英文 agent 生态，skill 正文逻辑与语言无关

## 安装

```bash
npx skills add difcn2026/skills
```

或直接下载本仓库，将对应 skill 目录放入你所用 agent 的 skills 目录。
